# DeepVerify Machine Learning Pipeline

This directory defines the core DeepVerify manipulation-detection pipeline.

## Model Architecture

The DeepVerify inference engine relies on a dual-branch ensemble architecture designed to detect artifacts in different domains:

1. **Spatial Branch (EfficientNet-B0)**: Analyzes the RGB pixel space for visual inconsistencies, blending artifacts, and anatomical anomalies. This branch is also responsible for generating the **Grad-CAM (Gradient-weighted Class Activation Mapping)** heatmaps, which highlight regions of the image that strongly influenced the model's decision.
2. **Frequency Branch (2D FFT)**: Transforms the image into the frequency domain (calculating the magnitude spectrum) before passing it through an EfficientNet-B0 backbone. This branch excels at detecting periodic grid artifacts commonly introduced by the upsampling operations in Generative Adversarial Networks (GANs).

### Ensemble Policy
The production backend orchestrates these branches using the `ensemble-v1.0` policy. It applies a **60% / 40% weighted summation**:
- `60%` Spatial Score
- `40%` Frequency Score

The output is an **Authenticity Score** (`1.0` = Real, `0.0` = AI). 

## Training Data & Generalization Limitations

> **CRITICAL WARNING**: The models provided in this repository are strictly research prototypes and have narrow generalization capabilities.

- **Training Dataset**: The models were trained exclusively on a constrained dataset consisting of **70,000 FFHQ images (Real faces)** and **70,000 StyleGAN images (Fake faces)**.
- **Out-of-Distribution Performance**: Because the training data consists solely of aligned faces from a specific GAN architecture, the model's performance on "in-the-wild" images (e.g., landscapes, full-body shots) or images generated by modern diffusion models (e.g., Midjourney, Stable Diffusion, DALL-E) is **unproven and highly likely to be inaccurate**.
- **No Video Analysis**: Video manipulation detection (e.g., deepfakes via temporal inconsistencies) is **not supported** in this release. Previous experimental branches utilizing VideoMAE were concluded and are not integrated into the V2 API.

## Model Artifact Setup

To execute the pipeline locally, you must provide the compiled model weights. Due to size limitations, they are excluded from source control.

1. Create a directory named `deepverify-models/` at the root of the project.
2. Obtain the weights (`deepverify-spatial-v1.onnx` / `.pt` and `deepverify-frequency-v1.onnx` / `.pt`).
3. Place them in the `deepverify-models/` directory. The FastAPI backend expects this path by default.

*Note: Do not commit these weights to the repository.*
